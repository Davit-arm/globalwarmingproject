# Globby, 
Globby, a bot about global warming

Globby, is a bot, which's purpose is to teach the user about global warming by:
-sending it videos about it
-telling about it 
-telling you about its effects
-sending facts
-sending almost every city's tempreture
and other things

!global_warming_def
